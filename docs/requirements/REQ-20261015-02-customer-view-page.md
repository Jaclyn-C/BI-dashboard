# REQ-20261015-02 · 客户视图页面（下游可见订单预览）

> 状态：已确认（用户 2026-10-15 会话定稿）
> 背景：即将对下游客户开放订单查询接口（仅"已计入"订单）。本需求先在内部看板新增一个
> **客户视图页面**，展示客户调用该接口能看到的全部数据，作为口径预览与验收基准。

## 1. 需求内容

新增内部页面「客户可见订单」（登录态访问，路由 `/customer`）：

- 展示**已计入（included）订单**且仅订单本身的信息
- **范围边界（2026-10-15 用户定稿）：客户只可见已计入订单明细**——广告收入、KPI 数据卡、
  图表、任何聚合/分成数据一律不对客户暴露；未来供应商接口同样仅提供订单明细查询
- **禁止出现任何分类信息**：order_class / 已计入 / 被剔除 / 剔除等相关字段与文案一律不出现在
  接口响应与页面中（红线：客户不可推断剔除规则）
- 字段集（=未来供应商接口的字段集）：订单编号、时间（UTC）、国家（语种推断）、语种、
  币种、原币金额、美元金额（上游自报，缺失显示 —）、状态（已完成/已退款）
- 支持时间范围、币种、状态筛选；时间/币种/金额/美元排序；25 行/页分页

## 2. 技术要点

- 字段裁剪在**后端完成**（`GET /api/v1/dashboard/customer-orders` 强制 included + 投影输出），
  前端拿到的即最终形态——不从内部订单接口取数后在前端隐藏列
- 复用 OrdersCard（`hideClass` 变体：无类别列、无类别筛选）与 TimeFilters
- 真正的供应商接口（`/api/v1/supplier/**` + API key + 供应商隔离）**不在本需求**，
  仍待 B4（供应商实体/密钥/分配）确认后单独立项；届时以本页字段集为契约起点

## 3. 验收标准

1. 页面只显示已计入订单；响应 JSON 中不存在 `order_class` 键（测试断言）
2. 响应与页面均无任何分类/剔除相关字段与文案
3. 筛选/排序/分页可用；空区间显示空态
4. 后端 pytest（含新增测试）、前端 lint/build 全过
