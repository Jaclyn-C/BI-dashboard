## 3. 方案定型

**推荐购买**：腾讯云轻量应用服务器**香港**节点 2核2G（活动套餐约 ¥288/年）+ 便宜域名（.top/.xyz 约 ¥10/年）。总成本约 ¥25/月。

**部署形态**：单台服务器 Docker Compose 三容器——

```
Caddy（80/443，自动 HTTPS）
 ├─ 静态托管前端构建产物（SPA 回退）
 └─ /api/*、/healthz、/docs* 反代 → api:8000
FastAPI（单 worker，启动即迁移，进程内同步调度器）
PostgreSQL 16（不映射端口，仅 compose 内网可达）
```

**选型理由与淘汰项**：

| 选项 | 结论 | 原因 |
|---|---|---|
| 国内云服务器 | 淘汰 | 80/443 必须域名 ICP 备案（1-2 周） |
| 香港/海外节点 | 采纳 | 免备案，国内访问延迟可接受 |
| RackNerd 等美国 VPS（~$20/年） | 备选 | 更便宜但国内打开明显慢，不适合天天看的报表 |
| 阿里云按量 + 节省停机模式 | 姊妹方案 B | 平时关机只付磁盘钱（月 ¥10-25），访问零散时更省；见按量手册 |

**数据量评估**：订单数据几十万~几百万行约几个 GB，轻量自带 SSD 足够；备份保留 14 份同样占用很小。盘满（`df -h`）再升配套餐，数据卷随实例迁移。

## 4. 交付产物

| 文件 | 作用 |
|---|---|
| `backend/Dockerfile` + `.dockerignore` | 生产镜像：pip 安装项目 → 非 root 用户运行；启动命令 = `alembic upgrade head && uvicorn`（迁移幂等，升级零人工）；pip 源可用构建参数 `PIP_INDEX_URL` 覆盖 |
| `frontend/Dockerfile` + `.dockerignore` | 多阶段：node:20-alpine 里 `pnpm build` → 产物拷进 caddy:2-alpine 托管 |
| `compose.prod.yaml` | 三容器编排；postgres 不映射端口；`DATABASE_URL` 由编排覆盖指向内网库（不读 .env 里的本地开发值） |
| `deploy/Caddyfile` | 域名来自 `.env` 的 `DOMAIN`（环境变量，改域名无需重建镜像）；自动签/续 HTTPS 证书 |
| `deploy/deploy.sh` | **本地**一键部署/升级：tar 走 ssh 上传（排除 .env/data/.claude 等）→ 远端执行 setup-server.sh；服务器 .env 与数据卷不受影响 |
| `deploy/setup-server.sh` | **服务器**端脚本（幂等）：装 Docker → 首跑生成 `.env` 并自动填三个随机密钥 → 必填检查 → 构建启动 → 健康等待 |
| `deploy/backup.sh` | pg_dump gzip 到 `backups/`，保留 14 份；配 crontab 每日跑（指南 §6） |
| `.env.prod.example` | 生产配置模板；需手填仅 3 处：DOMAIN、SMTP_*（验证码邮件）、UPSTREAM_CLIENT_*（订单同步） |
| `docs/deployment/部署指南.md` | 傻瓜式全流程：买服务器 → 买域名解析 → 一条命令 → 填配置 → 验证清单 → 备份 → 排障 |
| `.gitignore` | 放行 `.env.prod.example`、忽略 `backups/` |
| `.claude/memory/deployment.md` | 收录生产落地形态与坑，供后续 Agent 查阅 |

**关键设计点**：

- 单 worker：同步调度器是进程内 asyncio 任务，多 worker 会重复同步（见 `app/upstream/scheduler.py`）
- 密钥自动生成：`SECRET_KEY` / `ORDER_FILTER_SALT` / `POSTGRES_PASSWORD` 首跑随机生成；**后两者一经使用永不可换**（换盐会导致新旧订单判定不一致）
- 生产强校验沿用现有代码：`ENVIRONMENT=production` 下弱 SECRET_KEY / 空盐值直接拒启动
- 前端零改动：请求走相对路径 `/api/v1`，同源反代天然成立

- ✅ 3 个 Alembic 迁移自动执行（auth → ingest → order_tag_backfill）
- ✅ 经 Caddy 反代验证：`/healthz` 返回 ok、SPA index.html 正常、`/openapi.json` 正常、登录接口空参 422（到达后端校验层）
- ✅ `backup.sh` 产出 gzip 校验完整；冒烟后 `down -v` 清理干净

**未验证（附原因）**：

- ❌ 公网真实证书签发：需要真实服务器与域名，首次部署时验证
- ❌ 上游同步在容器内运行：冒烟关闭了同步（不碰生产数据）；首次部署后看 `logs api` 确认

**排坑记录**（已修，记入 memory）：

1. **pnpm 12 拦截依赖构建脚本**：干净环境 `pnpm install` 报 `ERR_PNPM_IGNORED_BUILDS: esbuild`——`package.json` 里旧的 `pnpm.onlyBuiltDependencies` 字段 pnpm 12 不再认（本地能跑是因为 `node_modules` 是老安装产物）。修法：镜像内 `pnpm install --frozen-lockfile --allow-build=esbuild`。曾测过 `package.json` 换 `pnpm.allowBuilds` 键与本机"通过"，但同版本 pnpm 容器内仍拦截，判定为假阳性，未采用。
2. **国内访问 PyPI / Docker Hub 龟速**：pip 下载 33 分钟未完成。修法：Dockerfile 加 `ARG PIP_INDEX_URL`（默认官方源，香港服务器直连无碍），国内本机构建传清华源；基础镜像用镜像源拉取后 retag（仅本机验证手段，生产文件保持官方源）。

## 6. 部署三步（摘要）

1. 买腾讯云轻量**香港** 2核2G（Ubuntu 24.04，防火墙放行 22/80/443）
2. 买便宜域名，A 记录指向服务器公网 IP
3. 本地项目根目录：`bash deploy/deploy.sh root@服务器IP` → 按提示填 3 处配置（域名 / SMTP / 上游凭据）→ 再跑一次同命令 → 打开 `https://域名` 注册使用

升级发版 = 同一条命令；每日备份 = crontab 一行。详见部署指南 §3-§7。
