# REQ-20261023-01 · 全局悬浮计算器

> 状态：已确认（用户 2026-10-23 会话委托："大概就是这么个意思"——细节委托设计）
> 背景：看数据时随手算比例/金额需要系统计算器，切出去麻烦。加一个不绑定页面的悬浮计算器。

## 1. 需求内容

### 1.1 悬浮计算器

功能说明：登录后的任意页面右下角有常驻【计算器】浮窗按钮，点击展开计算器面板；面板可按标题栏**任意拖动**（拖动范围钳制在视口内），**不绑定页面**——切换页面不关闭、不重置、位置保留；再点按钮或【关闭】收起，重新展开仍在最后位置。未登录的认证页不显示。

1. 打开/关闭：点击右下角【计算器】展开面板，再点或点面板内【关闭】收起；Esc 关闭。
2. 拖动：**浮窗按钮自身**与**面板任意非按键区域**均可拖动（视口内钳制）；位移 <3px 视为点击，不误触发开关；按键与【关闭】点击始终有效。
3. 表达式计算（v2，用户 2026-10-23 定稿——支持括号混合运算）：主行=**完整算式**（所按数字/运算符/括号全程可见、可 DEL 逐字退），副行=实时预览结果；【=】结算（未闭合括号自动补齐），结果上接运算符可续算、输入数字起新式。
4. 运算能力：+ − × ÷、括号分组、后缀 %（= ÷100）、一元负号、隐式乘法（`3(2+1)`、`(1+2)(3+4)`）；运算符连按覆盖、二元后接 − 为一元负号；除零/无效算式显示「错误」，任意键恢复。求值器为自研递归下降（约 60 行），不引第三方库。
5. 键盘：面板打开时支持数字/运算符/括号/Enter(=)/Backspace(DEL)/%/Esc 输入。

## 2. 边界与约束

- 纯本地工具：不请求接口、不读写业务数据；与金额纪律无关（用户自算，非业务渲染）。
- 极简文字风：无图标/emoji（红线 13），运算符为数学记号非图标；关闭为文字按钮。
- i18n：zh/en（标题/按钮/错误文案）；深色模式走 CSS 变量。

## 3. 口径变更清单

无。

## 4. 验收标准

1. 登录后每个页面（数据看板/客户订单/Offer 管理/用户管理）右下角均有【计算器】按钮，认证页无。
2. 浮窗按钮与面板均可拖动且钳制视口内；切换页面后位置与面板开合状态保留。
3. 括号混合运算正确（如 `(1+2)×3`=9、`3(2+1)`=9、`(1+2)(3+4)`=21）；% 为 ÷100；一元负号可用；除零显示错误并可恢复；0.1+0.2 显示 0.3。
4. 主行显示完整算式并可逐字退格；副行实时预览；等号自动补齐未闭合括号；结果可续算。
5. 键盘输入可用（含括号）；Esc 关闭。
6. zh/en 文案齐全；深色模式正常；无图标 emoji；lint/build 过。
