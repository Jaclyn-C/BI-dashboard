# 按量开关部署手册（方案 B：用户来了开机，月底释放）

> 玩法：阿里云**按量付费**实例 + **节省停机模式**——平时关机只付磁盘钱（几元/月），用户要看时手机点开机（约 1 分钟可用），月底备份后整台释放，计费归零。
> 适合：看板访问零散（每月开机总计几十小时）。只租一两个月怎么算都比包年便宜；若计划连续使用超过约 5 周，直接买国内 e 实例包年（¥99/年 ≈ ¥8.3/月，常开免开关）更省心。
> 选型过程见《[部署选型记录](部署选型记录.md)》。本文是方案 B 的唯一操作手册，自包含全流程：买机器 → 部署 → 日常开关 → 升级备份 → 月末释放 → 下月重建。

## 地域怎么选：不用域名就不涉及备案

备案绑定的是**域名**，不是服务器：不把域名解析到服务器、纯 IP 访问，**国内节点也不需要备案**（腾讯云备案 FAQ 原文：「当您不使用域名解析指向服务器时，不需要进行备案」；厂商的拦截系统针对的是未备案域名）。据此：

- **推荐国内节点**（如华东 1·杭州）：经济型 e 实例约 ¥0.094/小时，比香港（约 ¥0.14/时）便宜三分之一，国内用户打开看板更快。
- **什么时候选香港**：将来要绑域名上 HTTPS 正式对外时——域名解析到国内必须 ICP 备案（1-2 周），香港不用。届时按本手册换香港重买即可，部署命令不变。
- 小风险：个别厂商对纯 IP 的 80 端口建站执行尺度不一（偶发拦截/关停提示）。内部演示场景影响很小，真遇到就换香港，数据用 §6 备份迁移。

## 0. 前置（一次性，5 分钟）

1. 注册阿里云账号并完成实名认证。
2. **充值 ≥ ¥100**：按量付费要求账户可用余额不低于 100 元，不足会禁止开机甚至强制停机——这是本方案最大的坑。
3. 手机装「阿里云」App（日常开关靠它）。

## 1. 买按量实例（控制台约 10 分钟）

1. 打开 <https://ecs.console.aliyun.com> → 「实例」→「创建实例」→ 选**自定义购买**。
2. 计费模式：**按量付费**；地域：**国内就近（如华东 1·杭州）**，可用区随便选。
3. 实例规格：**经济型 e → ecs.e-c1m1.large（2核2G，约 ¥0.094/小时）**——无本地盘、支持节省停机模式；无货时在 2核2G 列表按价格从低到高选（避开带本地盘的 d/i 系列），以购买页为准。
4. 镜像：Ubuntu 22.04 或 24.04；系统盘：40 GiB ESSD Entry（最低档）。
5. 网络：保持默认**专有网络（VPC）**；公网带宽处**不要勾**「分配公网 IPv4」——下一步用 EIP 代替（关机不回收，IP 永不变）。
6. 安全组：新建，放行 `22`（SSH）、`80`（HTTP）、`443`（HTTPS）。
7. 登录凭证：设置 root 密码（记下来，§3 部署要用）。
8. 确认订单页脚显示约 ¥0.09-0.10/小时 即下单。

## 2. 买 EIP 并绑定（约 3 分钟）

1. 控制台顶部搜索「弹性公网 IP」→「申请 EIP」：按量付费、按使用流量计费，带宽峰值默认即可。
2. 申请到 IP 后点「绑定」→ 选刚创建的 ECS 实例。这个 IP 就是用户访问的地址，**记下来，下文写作 `<EIP>`**。
3. 费用：绑定在 ECS 上期间免配置费；只收出方向流量 ¥0.8/GB（看板一个月流量通常不足 1 元）。

> EIP 的作用：「节省停机模式」会回收实例的固定公网 IP，但不动 EIP——关机再开机 `<EIP>` 不变，用户收藏的地址不失效。

## 3. 首次部署（约 15 分钟：本机一条命令 → 服务器填配置 → 本机再跑一次）

前提：本机（Linux / macOS / Git Bash）能 `ssh root@<EIP>` 登录，root 密码在 §1 第 7 步设置。为免每次输密码，先在本机终端跑一次（输一遍密码，以后免密）：

```bash
ssh-copy-id root@<EIP>
```

**① 本机跑部署命令**（项目根目录）：

```bash
bash deploy/deploy.sh root@<EIP>
```

它会：上传代码 → 服务器装 Docker → 生成生产 `.env`（自动随机生成 `SECRET_KEY` / `ORDER_FILTER_SALT` / `POSTGRES_PASSWORD` 三个密钥，**后两者一经使用永不可换**：换盐会导致新旧订单判定不一致）→ 构建镜像 → 启动。

首跑预期停在「请先编辑 .env 填 DOMAIN」——**这是正常的**，继续 ②。

**② 服务器上填 3 处配置**：

```bash
ssh root@<EIP>
nano /opt/partner-dashboard/.env
```

对照下表填（其余行不用动）：

| 配置项 | 填什么 | 不填的后果 |
|---|---|---|
| `DOMAIN=` | `http://<EIP>`（纯 IP 明文 HTTP；已实测 Caddy 以 80 端口明文监听，浏览器无证书警告） | Caddy 起不来，部署脚本会拦住 |
| `SMTP_*` 六项 | 发件邮箱。QQ 邮箱：`smtp.qq.com` / `465` / 邮箱地址 / **授权码**（设置→账户→开启 SMTP 获得）/ 同邮箱地址 / `false` / `true`。本机开发用的 `backend/.env` 里有现成六行可照抄 | 收不到验证码 → 谁都注册/登录不了（生产无日志降级，发送直接失败） |
| `UPSTREAM_CLIENT_ID` / `UPSTREAM_CLIENT_SECRET` | 上游 netshort 凭据（同样照抄本机 `backend/.env` 的同名两行） | 不同步订单，看板无数据 |

保存退出（nano：`Ctrl+O` 回车，`Ctrl+X`）。

**③ 本机再跑一次同一条命令**，这次会跑完并打印部署完成：

```bash
bash deploy/deploy.sh root@<EIP>
```

**验证清单**：

- [ ] 浏览器打开 `http://<EIP>` → 出现登录页
- [ ] 注册：填邮箱 → 收验证码 → 设密码 → 进入看板（上游凭据已配则首次启动自动回填最近 92 天订单，需几分钟到几十分钟，数据渐全）
- [ ] 打开 `http://<EIP>/docs` → FastAPI 接口文档（给下游供应商看的）
- [ ] 服务器上 `docker compose -f compose.prod.yaml ps` → 三个容器都是 running/healthy

> 明文 HTTP 只适合内部演示，别在不可信网络登管理员账号。将来要正规 HTTPS：买 ~¥10/年 的域名，A 记录解析到 `<EIP>`，`.env` 的 `DOMAIN` 改填域名后重启即生效——注意域名解析到国内必须 ICP 备案（1-2 周），嫌慢可换香港节点按 §1 重建（部署命令不变），数据用 §6 备份迁移。

## 4. 日常开关（手机 2 下）

- **开机**：阿里云 App →「资源」→ 云服务器 ECS → 点实例 →「启动」→ 等 1-2 分钟（实测值：OS 启动 + 容器拉起 + 数据库就绪的全链路）→ 打开 `http://<EIP>`。所有容器自动拉起，关机期间漏掉的订单自动补同步（30 分钟一轮，无需干预）。
- **关机**：同路径 →「停用」→ 弹窗**务必勾选「节省停机模式」** → 确认。不勾 = 计算费照烧（约 ¥0.09/小时）。第一次关机后，次日到「费用中心」看一眼计算费确实停了。

## 5. 升级、备份与日常排障（服务器 /opt/partner-dashboard 下）

**升级发版**：本地改完代码提交后，再跑一次 `bash deploy/deploy.sh root@<EIP>`——与首次部署同一条命令，数据卷和 `.env` 不受影响。

**每日自动备份（部署完配一次，2 分钟）**：月中机器故障或误操作只有备份能救（月末释放另有 §6 兜底）。服务器上执行：

```bash
crontab -e
# 加一行（每天 04:10 备份数据库到 backups/，保留 14 份）：
10 4 * * * bash /opt/partner-dashboard/deploy/backup.sh
```

**速查**：

```bash
docker compose -f compose.prod.yaml ps          # 看状态
docker compose -f compose.prod.yaml logs -f api # 看后端日志（同步报错看这里）
docker compose -f compose.prod.yaml restart     # 重启全部
docker compose -f compose.prod.yaml down        # 停止（数据不丢）
```

## 6. 月末收尾（本机一条命令 + 控制台点 2 下）

```bash
bash deploy/teardown.sh root@<EIP>
```

脚本自动：在服务器上备份数据库 → 下载到本地 `backups/` → 校验备份非空（空备份会拦住不让继续）。然后到控制台：

1. ECS「实例」→ **释放**（释放后磁盘与计算费全部归零）。
2. 「弹性公网 IP」→ **释放**（只解绑不释放的话，闲置 EIP 收 ¥0.02/小时）。

> 备份保住的是注册用户、供应商 API key、人工调整等**本地数据**；订单数据不用管——92 天内的订单会在下次部署时自动从上游回填。

## 7. 下个月再用（重建 + 可选恢复）

重复 §1-§3（新实例会分到新 `<EIP>`，`.env` 里 `DOMAIN` 记得改）。上月数据要不要恢复分两种：

- **不在乎上月的注册用户/配置**：什么都不用做，新库直接重新注册（订单自动回填 92 天）。
- **要恢复**：部署完成后执行——

```bash
scp backups/pd-<日期>.sql.gz root@<EIP>:/tmp/
ssh root@<EIP> "cd /opt/partner-dashboard && \
  docker compose -f compose.prod.yaml exec -T postgres psql -U pd -d pd -c 'DROP SCHEMA public CASCADE; CREATE SCHEMA public;' && \
  gunzip -c /tmp/pd-<日期>.sql.gz | docker compose -f compose.prod.yaml exec -T postgres psql -U pd -d pd && \
  docker compose -f compose.prod.yaml restart api"
```

（先清空再导入，导入的 `alembic_version` 与代码一致；调度器会从备份里的同步水位继续增量补数据。）

## 8. 费用速查（国内 2核2G 按量约 ¥0.094/时 + 磁盘约 ¥5-10/月，关机照收）

| 每月开机时长 | 月费用 |
|---|---|
| 整月不开 | 约 ¥5-10（只剩磁盘） |
| 30 小时（每天 1 小时） | 约 ¥8-13 |
| 120 小时（每天 4 小时） | 约 ¥16-21 |
| 全天常开（720 小时） | 约 ¥75 —— 只租一个月仍低于包年 ¥99；**要连用超过约 5 周，直接买 e 实例包年 ¥99/年（¥8.3/月）** |

> 香港节点同用法各档约贵 40%（按量 ¥0.14/时）且磁盘更贵——不用域名就选国内。

## 9. 常见坑

1. 关机忘勾「节省停机模式」→ 计算费照烧。第一次关机后次日用账单核验。
2. 余额低于 ¥100 → 按量资源被停用、EIP 强制解绑。App 里设个余额预警，随欠随充。
3. 释放实例前**必须**先跑 `deploy/teardown.sh`——释放后本地数据（用户/key）不可恢复。
4. 开机偶发「库存不足」：节省停机模式回收了计算资源，重开时要重新分配。等几分钟重试或换个可用区。
5. 供应商程序化调用 API 的那天起，机器必须常开——本方案只适合人工看板。
6. 收不到验证码：`.env` 的 SMTP 没配对——QQ 邮箱必须用「授权码」不是登录密码，且 `SMTP_SSL=true`；改完在服务器 `docker compose -f compose.prod.yaml up -d` 重建生效。
7. 看板一直没数据：`UPSTREAM_CLIENT_ID/SECRET` 没填或填错；`docker compose -f compose.prod.yaml logs api` 看同步报错。
8. 磁盘将满：`df -h` 确认；先清旧备份（`ls backups/` 删最老的），还不够就在控制台扩容系统盘后重启实例。
