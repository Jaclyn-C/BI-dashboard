# 部署选型记录：低成本短期部署（2026-10-16）

> 背景：看板只需短期（约一个月）、零散使用——用户想访问时再开机，平时不烧钱。本文记录选型过程与结论，操作细节见《[按量开关部署手册](按量开关部署手册.md)》。
> 结论先行：**采纳方案 B——阿里云国内节点按量付费 + 节省停机模式，纯 IP 访问免备案，月成本约 ¥10-25。**

## 需求画像

- 使用一个月左右，之后可能释放，也可能下月再用。
- 访问零散：用户来了开机（约 1 分钟可用），走了关机。
- 配置要求低：本项目（FastAPI 单 worker + PostgreSQL 16 + Caddy）合计内存约 1G，2核2G/40G 盘足够。
- 无域名、内部演示用途，可接受明文 HTTP。

## 评估过的方案

### 1. 白嫖流（Cloudflare Pages + Vercel + Neon）——不适用

参考：掘金《白嫖，如何不花钱部署我的网站》（juejin.cn/post/7624357532246818857），该文方案适合静态 landing page / 轻量 serverless 项目。对本项目不匹配：

- Cloudflare Pages 只托管静态文件；Workers 是 JS/WASM 运行时，跑不了 FastAPI。
- Vercel 的 Python serverless 有执行时限与冷启动，且本项目同步调度器是**进程内 asyncio 常驻任务**（`app/upstream/scheduler.py`，镜像特意锁单 worker），serverless 模型不适配。
- Neon/Supabase 免费档有闲置回收/暂停政策——库中是真实合作伙伴收益数据，下游供应商 API 是正式契约，数据与可用性风险不可接受。

前端单独上 Cloudflare Pages 可行，但 API 仍需常驻服务器，省不到点上，不做。

### 2. 按量付费 + 节省停机模式（方案 B）——✅ 采纳

阿里云「节省停机模式」：关机时释放 vCPU/内存/固定公网 IP 不计费，保留云盘与配置，随时开机恢复（腾讯云有等价政策）。关键配套：

- **EIP（按流量计费）**：绑定 ECS 期间免配置费，只收出方向流量 ¥0.8/GB（看板每月流量费 <¥1）；固定公网 IP 关机会被回收，EIP 不会。
- **项目侧零改动**：全部容器 `restart: unless-stopped`，开机自动拉起；调度器首次启动回填 92 天订单，关机断档开机自动补齐（幂等）。
- 日常开关 = 阿里云 App 点两下；月末 `deploy/teardown.sh` 备份下载后释放实例 + EIP，计费归零。

**备案关键发现**：备案绑定的是域名而非服务器。不使用域名解析、纯 IP 访问（`DOMAIN=http://<EIP>`，已用 caddy adapt 实测生成 `:80` 明文监听），**国内节点也无需备案**（腾讯云备案 FAQ：「当您不使用域名解析指向服务器时，不需要进行备案」）。因此地域选国内（华东 1·杭州），经济型 e 实例 `ecs.e-c1m1.large` 约 ¥0.094/时，比香港（~¥0.14/时）便宜三分之一且访问更快。将来要域名 + HTTPS 时再换香港（域名解析国内必须 ICP 备案 1-2 周），部署命令不变。

**备选子方案 A（这月天天开才用）**：轻量应用服务器只买 1 个月、关自动续费（约 ¥30-60/月）。开机密度高时比按量省心。

### 3. CompShare（优云智算）——不采用

UCloud 旗下 GPU 算力租用平台，无卡模式最低 2核4G ¥0.15/时，比阿里云 e 实例贵 60%，且其定位是"挂 GPU 前的数据上传/环境调试过渡态"，不是 Web 服务托管场景，无对外建站的 SLA 承诺。价格与场景双输，排除。

## 费用速查（方案 B，国内 2核2G）

| 每月开机时长 | 月费用 |
|---|---|
| 整月不开 | 约 ¥5-10（只剩磁盘） |
| 30 小时（每天 1 小时） | 约 ¥8-13 |
| 120 小时（每天 4 小时） | 约 ¥16-21 |
| 全天常开 | 约 ¥75 |

分界线：只租一个月任何用法都低于包年 ¥99；**计划连续使用超过约 5 周，直接买 e 实例包年 ¥99/年（¥8.3/月，常开免开关）**。

## 风险与边界

1. 账户余额需 ≥¥100，不足按量资源会被停机——最大运营坑，手册已列。
2. 关机必须手动勾选「节省停机模式」，默认不勾，不勾计算费照烧；首次关机后次日用账单核验。
3. 纯 IP 是明文 HTTP：内部演示够用，不可信网络勿登管理员；要正规 HTTPS 再买域名（~¥10/年）。
4. 开关玩法只适合人工看板——**有供应商程序化调用 API 的那天起机器必须常开**。
5. 个别厂商对纯 IP 80 端口建站执行尺度不一（偶发拦截），遇到则换香港节点，用 §5 备份迁移。
