# REQ-20261022-01 · 侧边栏导航布局（页面框架改版）

> 状态：已确认（用户 2026-10-22 会话确认，待确认项 1-4 均按建议默认执行）
> 背景：当前登录后三个页面（看板、客户视图、用户管理）共用顶部应用栏，页面间靠应用栏里的
> 跳转按钮（【客户视图】【用户管理】【返回看板】）互跳，入口分散且随页面变化。本需求把整体
> 布局改为**固定侧边栏导航**，入口统一；现有看板数据在侧边栏中定名「数据看板」。

## 1. 需求内容

### 1.1 侧边栏导航

功能说明：超管、管理员、客户在登录后的任意页面左侧可见固定侧边栏，侧边栏按角色显示其有权访问的页面入口（数据看板、客户视图、用户管理，按此顺序排列），当前所在页面对应入口高亮标识；切换页面时侧边栏保持可见，高亮随当前页面同步，无权限的入口对该角色不显示。

1. 切换页面：在侧边栏点击入口（如【客户视图】），跳转到对应页面，被点击项转为高亮、原高亮取消，若点击的已是当前页面则不做任何跳转与变化。
2. 角色可见性：超管/管理员侧边栏显示【数据看板】【客户视图】【用户管理】三项；客户仅显示【客户视图】一项；待分配用户（等待分配权限页）不显示侧边栏，页面维持现状。
3. 当前项标识：高亮仅以文字强调与左侧标记线呈现（跟随现有极简文字风格），不引入任何图标。

### 1.2 顶栏精简

功能说明：超管、管理员、客户登录后页面顶部保留现有应用栏承载全局信息与操作（应用标题、副标题/状态行、语言切换、刷新、退出，数据说明按钮仍仅在看板页出现），页面跳转入口全部移入侧边栏，顶栏不再出现【客户视图】【用户管理】【返回看板】等跳转按钮。

1. 全局操作：顶栏【语言切换】【刷新】【退出】及看板页【数据说明】的现有行为不变；【刷新】仍仅在有意义的数据页（数据看板、客户视图）出现。
2. 跳转入口清理：原顶栏跳转按钮全部移除，其功能由侧边栏承接，若某页面侧边栏与顶栏出现重复入口则以侧边栏为准。

### 1.3 「数据看板」定名

功能说明：现有看板页（KPI、每日收益、口径对比、国家分布、订单明细等全部数据内容）在侧边栏入口定名为「数据看板」，页面内容与全部数据口径不变；应用标题「合作方数据看板」维持不变，仅作为产品名展示。

1. 入口命名：侧边栏首项为【数据看板】，点击进入现有看板页，页面数据、筛选、导出等行为完全不变。

## 2. 边界与约束

- **纯前端改版**：后端接口、鉴权、角色规则均不变；页面地址（路由）不变，仅布局与导航变化。
- **窄屏可用**：沿用现有窄屏标准（375px 无遮挡），窄屏下侧边栏收纳为页面顶部（顶栏之下）的横向导航行，点击行为与高亮规则同侧边栏。
- **深色模式**：侧边栏配色纳入现有 CSS 变量体系，深浅色模式下均正常呈现。
- **i18n**：侧边栏文案中英双语（数据看板 / Data dashboard 等），无硬编码文案。

## 3. 口径变更清单

无业务口径变更（分成、汇率、聚合、数据集定义均不动）。

## 4. 影响面

- 前端：页面框架（侧边栏 + 顶栏）、三个登录后页面共用布局、i18n（新增侧边栏词条、移除 navTo/navBack 跳转按钮词条）、dashboard.css 布局样式与窄屏适配。
- 后端：无。
- 下游供应商接口：无。

## 5. 验收标准

1. 超管/管理员登录后任意页面（数据看板/客户视图/用户管理）左侧均有侧边栏，含【数据看板】【客户视图】【用户管理】三项且顺序正确，当前页高亮。
2. 客户登录后侧边栏仅见【客户视图】；待分配页无侧边栏。
3. 顶栏不再出现任何页面跳转按钮；语言切换/刷新/退出/数据说明行为与改版前一致。
4. 现有看板页数据内容与操作（筛选/数据集/CSV/图表）与改版前逐项一致。
5. 375px 宽度下页面可用无遮挡（沿 AC-R1），侧边栏以横向导航行呈现。
6. 深色模式下侧边栏正常；无图标、无 emoji（红线 13）。
7. zh/en 文案齐全无硬编码；前端 lint、build 全过；后端零改动。
