# 按量开关部署手册（方案 B：用户来了开机，月底释放）

> 玩法：阿里云**按量付费**实例 + **节省停机模式**——平时关机只付磁盘钱（几元/月），用户要看时手机点开机（约 1 分钟可用），月底备份后整台释放，计费归零。
> 适合：看板访问零散（每月开机总计几十小时）。只租一两个月怎么算都比包年便宜；若计划连续使用超过约 5 周，直接买国内 e 实例包年（¥99/年 ≈ ¥8.3/月，常开免开关）更省心。
> 与《[部署指南](部署指南.md)》的关系：首次部署的三步曲（一条命令部署 → 填 `.env` → 验证）完全复用部署指南 §3-§5，本手册只讲"按量"特有的四件事：买按量实例、买 EIP、日常开关、月末释放。

## 地域怎么选：不用域名就不涉及备案

备案绑定的是**域名**，不是服务器：不把域名解析到服务器、纯 IP 访问，**国内节点也不需要备案**（腾讯云备案 FAQ 原文：「当您不使用域名解析指向服务器时，不需要进行备案」；厂商的拦截系统针对的是未备案域名）。据此：

- **推荐国内节点**（如华东 1·杭州）：经济型 e 实例约 ¥0.094/小时，比香港（约 ¥0.14/时）便宜三分之一，国内用户打开看板更快。
- **什么时候选香港**：将来要绑域名上 HTTPS 正式对外时——域名解析到国内必须 ICP 备案（1-2 周），香港不用。届时按本手册换香港重买即可，部署命令不变。
- 小风险：个别厂商对纯 IP 的 80 端口建站执行尺度不一（偶发拦截/关停提示）。内部演示场景影响很小，真遇到就换香港，数据用 §5 备份迁移。

## 0. 前置（一次性，5 分钟）

1. 注册阿里云账号并完成实名认证。
2. **充值 ≥ ¥100**：按量付费要求账户可用余额不低于 100 元，不足会禁止开机甚至强制停机——这是本方案最大的坑。
3. 手机装「阿里云」App（日常开关靠它）。

## 1. 买按量实例（控制台约 10 分钟）

1. 打开 <https://ecs.console.aliyun.com> → 「实例」→「创建实例」→ 选**自定义购买**。
2. 计费模式：**按量付费**；地域：**国内就近（如华东 1·杭州）**，可用区随便选。
3. 实例规格：**经济型 e → ecs.e-c1m1.large（2核2G，约 ¥0.094/小时）**——无本地盘、支持节省停机模式；无货时在 2核2G 列表按价格从低到高选（避开带本地盘的 d/i 系列），以购买页为准。
4. 镜像：Ubuntu 22.04 或 24.04；系统盘：40 GiB ESSD Entry（最低档）。
5. 网络：保持默认**专有网络（VPC）**；公网带宽处**不要勾**「分配公网 IPv4」——下一步用 EIP 代替（关机不回收，IP 永不变）。
6. 安全组：新建，放行 `22`（SSH）、`80`（HTTP）、`443`（HTTPS）。
7. 登录凭证：设置 root 密码（记下来，deploy.sh 要用）。
8. 确认订单页脚显示约 ¥0.09-0.10/小时 即下单。

## 2. 买 EIP 并绑定（约 3 分钟）

1. 控制台顶部搜索「弹性公网 IP」→「申请 EIP」：按量付费、按使用流量计费，带宽峰值默认即可。
2. 申请到 IP 后点「绑定」→ 选刚创建的 ECS 实例。这个 IP 就是用户访问的地址，**记下来，下文写作 `<EIP>`**。
3. 费用：绑定在 ECS 上期间免配置费；只收出方向流量 ¥0.8/GB（看板一个月流量通常不足 1 元）。

> EIP 的作用：「节省停机模式」会回收实例的固定公网 IP，但不动 EIP——关机再开机 `<EIP>` 不变，用户收藏的地址不失效。

## 3. 首次部署（复用部署指南）

在项目根目录（本机）执行：

```bash
bash deploy/deploy.sh root@<EIP>
```

预期停在「请先编辑 .env 填 DOMAIN」——**这是正常的**。接着按部署指南 §4 填三处配置，其中 `DOMAIN` 无域名时填：

```
DOMAIN=http://<EIP>
```

（已验证：Caddy 会以 HTTP 明文监听 80 端口，浏览器无证书警告。明文 HTTP 只适合内部演示，别在不可信网络登管理员账号；要正规 HTTPS 就按部署指南 §2 买 10 元/年域名解析到 `<EIP>`，`DOMAIN` 填域名。）

`SMTP_*`（QQ 邮箱授权码）和 `UPSTREAM_CLIENT_*` 的填法照抄部署指南 §4 表格——**SMTP 不填则收不到验证码，谁都注册不了**。填完 `docker compose -f compose.prod.yaml up -d` 重启，浏览器打开 `http://<EIP>` 注册即完成。首次启动自动回填最近 92 天订单，等几分钟数据更全。

## 4. 日常开关（手机 2 下）

- **开机**：阿里云 App →「资源」→ 云服务器 ECS → 点实例 →「启动」→ 等约 1 分钟 → 打开 `http://<EIP>`。所有容器自动拉起，关机期间漏掉的订单自动补同步（30 分钟一轮，无需干预）。
- **关机**：同路径 →「停用」→ 弹窗**务必勾选「节省停机模式」** → 确认。不勾 = 计算费照烧（约 ¥0.09/小时）。第一次关机后，次日到「费用中心」看一眼计算费确实停了。

## 5. 月末收尾（本机一条命令 + 控制台点 2 下）

```bash
bash deploy/teardown.sh root@<EIP>
```

脚本自动：在服务器上备份数据库 → 下载到本地 `backups/` → 校验备份非空（空备份会拦住不让继续）。然后到控制台：

1. ECS「实例」→ **释放**（释放后磁盘与计算费全部归零）。
2. 「弹性公网 IP」→ **释放**（只解绑不释放的话，闲置 EIP 收 ¥0.02/小时）。

> 备份保住的是注册用户、供应商 API key、人工调整等**本地数据**；订单数据不用管——92 天内的订单会在下次部署时自动从上游回填。

## 6. 下个月再用（重建 + 可选恢复）

重复 §1-§3（新实例会分到新 `<EIP>`，`.env` 里 `DOMAIN` 记得改）。上月数据要不要恢复分两种：

- **不在乎上月的注册用户/配置**：什么都不用做，新库直接重新注册（订单自动回填 92 天）。
- **要恢复**：部署完成后执行——

```bash
scp backups/pd-<日期>.sql.gz root@<EIP>:/tmp/
ssh root@<EIP> "cd /opt/partner-dashboard && \
  docker compose -f compose.prod.yaml exec -T postgres psql -U pd -d pd -c 'DROP SCHEMA public CASCADE; CREATE SCHEMA public;' && \
  gunzip -c /tmp/pd-<日期>.sql.gz | docker compose -f compose.prod.yaml exec -T postgres psql -U pd -d pd && \
  docker compose -f compose.prod.yaml restart api"
```

（先清空再导入，导入的 `alembic_version` 与代码一致；调度器会从备份里的同步水位继续增量补数据。）

## 7. 费用速查（国内 2核2G 按量约 ¥0.094/时 + 磁盘约 ¥5-10/月，关机照收）

| 每月开机时长 | 月费用 |
|---|---|
| 整月不开 | 约 ¥5-10（只剩磁盘） |
| 30 小时（每天 1 小时） | 约 ¥8-13 |
| 120 小时（每天 4 小时） | 约 ¥16-21 |
| 全天常开（720 小时） | 约 ¥75 —— 只租一个月仍低于包年 ¥99；**要连用超过约 5 周，直接买 e 实例包年 ¥99/年（¥8.3/月）** |

> 香港节点同用法各档约贵 40%（按量 ¥0.14/时）且磁盘更贵——不用域名就选国内。

## 8. 常见坑

1. 关机忘勾「节省停机模式」→ 计算费照烧。第一次关机后次日用账单核验。
2. 余额低于 ¥100 → 按量资源被停用、EIP 强制解绑。App 里设个余额预警，随欠随充。
3. 释放实例前**必须**先跑 `deploy/teardown.sh`——释放后本地数据（用户/key）不可恢复。
4. 开机偶发「库存不足」：节省停机模式回收了计算资源，重开时要重新分配。等几分钟重试或换个可用区。
5. 供应商程序化调用 API 的那天起，机器必须常开——本方案只适合人工看板。
